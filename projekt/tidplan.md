# Tidplan och beroenden

## Faser

| Fas | Beroenden | Klart när |
|---|---|---|
| Förstudie och nuläge | – | Mått, foton och befintliga installationer dokumenterade |
| Krav och design | Förstudie | Planlösning, materialprinciper och funktionskrav beslutade |
| Offerter | Krav och design | Omfattning jämförbar och entreprenörer valda |
| Inköp | Beslutade produkter | Kritiska produkter beställda med verifierade leveranstider |
| Rivning | Startbeslut | Befintligt badrum öppnat och avvikelser dokumenterade |
| VVS och el | Rivning | Dolda installationer färdiga och dokumenterade |
| Underarbete | VVS och el | Väggar, golv och fall klara för tätskikt |
| Tätskikt | Underarbete | Tätskikt utfört och dokumenterat |
| Ytskikt | Tätskikt | Kakel/klinker och fogning färdiga |
| Installation | Ytskikt | Porslin, blandare, dusch, belysning och inredning monterade |
| Slutkontroll | Installation | Avvikelser stängda och dokumentation komplett |

## Kritiska beroenden

- Produktval måste vara låsta innan måttkritiska installationer görs.
- Golvbrunn, fall och tätskiktslösning måste samordnas.
- Elpunkter och belysning måste beslutas innan väggar stängs.
- Dolda installationer ska fotograferas innan de byggs in.
- Leveranstider på måttbeställda produkter kan styra hela slutdatumet.

## Milstolpar

- M1: Projektomfattning beslutad
- M2: Entreprenad och huvudprodukter valda
- M3: Rivning klar
- M4: Dolda installationer verifierade
- M5: Tätskikt klart
- M6: Installation klar
- M7: Slutbesiktning godkänd
