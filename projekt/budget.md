# Budget

## Budgetprincip

Budgeten ska skilja mellan beslutad kostnad, prognos och faktisk kostnad. Alla större inköp bör kunna kopplas till ett Issue eller ett dokumenterat beslut.

| Reserv/buffert |  |  |  | Ej estimerad |

## Regler

- Ny kostnadspost ska dokumenteras innan beställning.
- Ändringar som påverkar totalbudgeten ska beskrivas i beslut eller Issue.
- Prognosen uppdateras när offert eller beställning finns.
- Utfall uppdateras när faktura eller slutkostnad är känd.
