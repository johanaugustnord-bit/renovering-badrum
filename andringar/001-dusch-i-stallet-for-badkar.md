# Ändringsförslag 001 – dusch i stället för badkar

## Bakgrund

Detta är ett demonstrationsförslag för att visa hur en fysisk projektförändring kan hanteras via GitHub Pull Request.

## Föreslagen ändring

Byt målbild från badkar till duschlösning.

## Konsekvenser att bedöma

- planlösning och fria mått
- VVS-placering och blandare
- duschvägg eller duschdörr
- golvfall och tätskiktsdetaljer
- materiallista
- budget
- leveranstider
- berörda Issues

## Roller som ska involveras

- Byggherre: beslut
- Huvudentreprenör: samordning och konsekvensbedömning
- VVS: teknisk påverkan på vatten/avlopp
- Plattsättare: påverkan på fall, tätskikt och ytskikt
- Leverantör/materialansvarig: produkt- och leveransinformation

## Beslut

Status: **Förslag – ej godkänt**

Förslaget ska inte betraktas som beslutat förrän Pull Requesten har granskats och mergats.
