# AGENTS.md

Detta repository representerar ett badrumsrenoveringsprojekt, inte ett mjukvaruprojekt.

## Arbetssätt

- GitHub är projektets gemensamma system of record.
- Issues beskriver arbete, ansvar, blockerare och restpunkter.
- Projektfiler beskriver krav, budget, tidplan, beslut, kvalitet och material.
- Större förändringar bör ske via branch och Pull Request.
- Ändra inte en annan yrkesrolls ansvar utan att tydligt dokumentera varför.
- Registrera avvikelser som Issues istället för att gömma dem i fritext.
- Uppdatera beslut och konsekvenser när ett val påverkar budget, tidplan eller andra roller.

## Agent-per-roll

Varje mänsklig deltagare använder sin egen ChatGPT eller Codex och arbetar utifrån sin roll.

När du startar en uppgift:
1. Identifiera användarens roll.
2. Läs relevanta Issues och projektfiler.
3. Sammanfatta vad rollen ansvarar för just nu.
4. Identifiera blockerare och beroenden.
5. Föreslå eller genomför endast administrativa ändringar som ligger inom rollen.
6. Skapa tydliga överlämningar till nästa roll.

## Roller

Se `projekt/roller-och-ansvar.md` för byggherre, huvudentreprenör, VVS, elektriker, snickare, plattsättare, målare, leverantör och besiktning.

## Säkerhets- och ansvarsnivå

AI-agenten får hjälpa till med administration, dokumentation, analys, spårbarhet och uppföljning. Den ska inte utge sig för att ersätta behöriga yrkespersoners tekniska eller regulatoriska bedömningar.
